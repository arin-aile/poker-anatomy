# Poker Anatomy

플레잉 카드의 규칙과 움직임을 관찰하는 인터랙션 아카이브.

## 구성
- 표준 텍사스 홀덤 족보 10종
- 카드 취급 및 딜러 동작 13종
- 한 판의 흐름 11단계 (폴드로 끝나는 분기 포함)
- 플레이어 기본 행동 5종
- HTML/CSS 애니메이션, 리플레이, 모바일 레이아웃
- 외부 이미지·폰트·JavaScript 의존성 없음

## 실행
`index.html`을 브라우저에서 열면 됩니다.

## GitHub Pages
저장소 루트에 파일을 업로드한 뒤 Settings → Pages에서 배포 소스를 Deploy from a branch, 브랜치를 main, 폴더를 / (root)로 설정합니다.
